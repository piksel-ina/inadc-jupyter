# Beginner's Guide

---

The Beginner's Guide introduces Jupyter notebooks, the Open Data Cube, xarray, and Earth observation workflows. It is written for people with a basic familiarity with Python and assumes no previous experience with the Open Data Cube.

The notebooks form a learning path and are best completed in order.

## Learning path

1. [Introduction to Jupyter notebooks](./01_jupyter_notebook_introduction.ipynb) introduces JupyterLab, notebook cells, kernels, and common file operations.
2. [Introduction to the Open Data Cube](./02_odc_introduction.ipynb) connects to the Open Data Cube and inspects its products and measurements.
3. [Loading data from the Open Data Cube](./03_loading_data.ipynb) finds and loads satellite data for a selected area and time range.
4. [xarray for the Open Data Cube](./04_xarray_for_odc.ipynb) explains the xarray structures returned by the Open Data Cube.
5. [Plotting xarray data from the Open Data Cube](./05_plotting.ipynb) plots individual bands, colour composites, and observations across time.

## Exercise

[Beginner's Guide exercise](./EXERCISE_Beginners_Guide.ipynb) provides practice in applying the Open Data Cube, xarray, and plotting skills covered in the guide to a different study area. One possible solution is available in the [Beginner's Guide exercise solution](./SOLUTION_Beginners_Guide.ipynb).
