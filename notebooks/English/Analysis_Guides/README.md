# Analysis Guides

---

> **Status:** This module is under development.

The Analysis Guides will cover reusable methods for analysing Earth observation data with the Open Data Cube and xarray. They will build on the [Beginner's Guide](../Beginners_Guide/README.md) and the [Data Product Guides](../Data_Product_Guides/README.md).

## Planned guides

- Data quality and cloud masking
- Spectral indices
- Temporal composites
- Time-series analysis
- Change detection

## Reference notebooks

The following notebook was authored by [Alex Leith](https://github.com/alexgleith). It is retained as a reference while this series is developed, and its examples will inform the notebooks created for the planned guides.

- [Basic analysis](05_BasicAnalysis.ipynb)

Each guide will explain the method, its data requirements, the main processing steps, and the interpretation of its output. The methods will support the complete applications presented in the existing [Case Studies](../Case_Studies/).
